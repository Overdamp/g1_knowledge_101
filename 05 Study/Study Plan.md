# Study Plan: 6 สัปดาห์ จาก "รันตาม" เป็น "เขียนเอง"

พื้นที่ฝึก: `~/g1_study/` (git repo ของคุณเอง) · sim: `~/g1_study/start_sim.sh` (G1 23-DoF, domain 1, `lo`, มี elastic band)
**ทุกโค้ดในแผนนี้คุณเขียนเอง** Claude ให้แค่โจทย์ คำใบ้ และรีวิว (โหมดติวเตอร์)

## กติกา 5 ข้อ
1. **เขียนเองก่อนดูของที่มี** ติดเกิน 20 นาทีค่อยขอคำใบ้ ห้ามก็อปจาก repo หลัก
2. **ทายก่อนรัน** เขียนลง "บันทึกการทาย" ของสัปดาห์นั้นก่อนกด Enter
3. **อธิบายด้วยคำของตัวเอง** จบแต่ละวันเขียนสรุป 3–5 บรรทัดโดยไม่เปิดโน้ต
4. **ทำให้พังแล้วซ่อม** เปลี่ยนทีละอย่าง ดูว่าอะไรเปลี่ยน
5. **ทวนซ้ำ** ตอบ "คำถามทวน" ของสัปดาห์ก่อนๆ อีกครั้งที่ +1 วัน, +3 วัน, +7 วัน (ตอบก่อน แล้วค่อยเปิดดู)

## ขอคำใบ้จาก Claude แบบไหน
| พิมพ์ | ได้อะไร |
|---|---|
| `ใบ้ 1` | ทิศทาง (ไปดูไฟล์ไหน / แนวคิดอะไร) |
| `ใบ้ 2` | ชื่อฟังก์ชัน / โครงสร้างที่ต้องใช้ |
| `ใบ้ 3` | โค้ดบางส่วนที่ขาด (ยังต้องต่อเอง) |
| `รีวิว <ไฟล์>` | ชี้จุดผิดและเหตุผล ไม่แก้ให้ |
| `เฉลย` | ใช้เมื่อทำเสร็จแล้วอยากเทียบเท่านั้น |

## สัปดาห์ 1: DDS และข้อมูลหุ่น
**เป้าหมาย:** เขียนโปรแกรมอ่าน `rt/lowstate` จาก sim ได้เอง และเข้าใจว่าข้อมูลมาถึงโปรแกรมได้อย่างไร
**โฟลเดอร์:** `~/g1_study/week1/`

### งาน
- [ ] **1.1 เปิด sim** `~/g1_study/start_sim.sh` เห็นหุ่นห้อยด้วย elastic band
- [ ] **1.2 `read_lowstate.py`**: พิมพ์ "ได้ข้อความแล้ว" ทุกครั้งที่ได้ LowState (ยังไม่ต้องแกะข้อมูล)
- [ ] **1.3** นับว่าได้กี่ข้อความต่อวินาที (Hz) พิมพ์ทุก 1 วินาที
- [ ] **1.4** พิมพ์มุม `q` ของ **ศอกซ้าย** (slot 18) เป็นองศา แล้วลากแขนหุ่นใน MuJoCo ดูค่าเปลี่ยน
- [ ] **1.5** พิมพ์ตาราง 23 ข้อต่อ: ชื่อ, q (rad), dq, อุณหภูมิ (อัพเดททุก 0.5 s ไม่ใช่ทุกข้อความ)
- [ ] **1.6** พิมพ์ roll / pitch / yaw ของ IMU เป็นองศา และ `mode_machine`
- [ ] **1.7 (ท้าทาย)** ใส่ argument `--iface` / `--domain` (argparse) ให้ใช้กับหุ่นจริงได้ (`enp43s0`, domain 0) และลองกับหุ่นจริงตอนมีโอกาส (อ่านอย่างเดียว ปลอดภัย)
- [ ] **1.8 ทำให้พัง:** รันโปรแกรมด้วย domain 0 ในขณะที่ sim อยู่ domain 1 → เกิดอะไร? ปิด multicast ของ `lo` (ถามก่อนทำ) แล้วรันใหม่ → เกิดอะไร?

### คำถามทวน (ตอบโดยไม่เปิดโน้ต)
1. DDS คืออะไร ต่างจากการเรียกฟังก์ชันตรงๆ อย่างไร
2. `ChannelFactoryInitialize(domain, iface)` สองค่านี้คืออะไร ทำไม sim ใช้ 1 แต่หุ่นจริงใช้ 0
3. callback (handler) ของ subscriber ถูกเรียกเมื่อไหร่ อยู่ thread เดียวกับ `main` ไหม
4. ทำไม LowState มี 35 ช่องมอเตอร์ แต่หุ่นเรามี 23 ข้อต่อ ช่องไหนว่าง
5. ทำไมต้องเปิด multicast บน `lo` แต่หุ่นจริงไม่ต้อง

## สัปดาห์ 2: PD control (ร่าง)
- [ ] ส่ง `rt/lowcmd` ให้ศอกซ้ายข้อเดียวขยับ step ใน sim (ข้อต่ออื่น damping) ต้องมี CRC
- [ ] คำนวณ `tau = kp(q_des − q) + kd(dq_des − dq)` เอง เทียบกับ `tau_est`
- [ ] ลอง kp 5 / 14.3 / 40 แล้ววัดเวลาที่ข้อต่อไปถึงเป้า (rise time)
- คำถามทวน: kp กับ kd ทำหน้าที่ต่างกันอย่างไรในทางฟิสิกส์ ทำไม kp สูงไปแล้วสั่น
